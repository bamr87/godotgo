# PRD — GodotGo

> Product requirements for [`bamr87/godotgo`](https://github.com/bamr87/godotgo).
> Derived from the README, agent docs, config and code in this repo. Anything not
> stated in those sources is marked **TBD**; success metrics are proposals.

## 1. Overview / problem

A Godot 4 game workspace: one reusable framework addon (`addons/godotgo`) symlinked into every game, five sample games that exercise it, project-aware tooling that verifies/tests/runs/exports every game identically, and a Claude Code integration that can build, test and improve them.

## 2. Target users

- Developers building small Godot 4 games who want a shared framework and tooling
- AI agents (Claude Code) improving games in a verifiable loop

## 3. Goals and non-goals

**Goals**

- Keep one framework shared across all games
- Make verification (`tools/verify.sh`) deterministic across host, Docker and CI with a pinned Godot (4.7.2)
- Scaffold new games that pass verification on creation

**Non-goals**

- Hand-drawn art (placeholder assets are generated)
- Making the optional Godot AI editor bridge a build input

## 4. Core features (current)

- Framework addon with zero-dependency test runner
- Sample games: orb-run, leap, swarm, shift, cascade
- Tools: install_godot, verify, run, export, new_game
- Generated placeholder sprites/sounds/meshes (`tools/gen_assets.py`) checked in CI
- Docker image and CI verifying every project in parallel
- Claude Code settings, hooks, subagents and skills

## 5. Requirements

**Functional**

- FR1: `tools/verify.sh` checks engine-version pins, tests and smoke-boots every project
- FR2: `tools/new_game.sh` returns only verified scaffolds
- FR3: CI fails if regenerated assets differ from committed ones
- FR4 (planned): Games can import AI-generated character sprite sheets (8 directions, multi-state animations) produced by [PerfectPixel Studio](https://github.com/gykim80/perfectpixel-studio) as `SpriteFrames` without hand editing

**Non-functional**

- NFR1: Engine version pinned in one place (`tools/lib.sh`)
- NFR2: Commit `.gd.uid` and `.import` sidecars; never `.godot/`
- NFR3: Scheduled improve agent gated by `vars.CLAUDE_IMPROVE_ENABLED`

## 7. Roadmap / open questions

- Export/distribution targets: TBD
- **Planned — integrate PerfectPixel Studio ([GODOTGO-007](features/features.yml), FR4).** [gykim80/perfectpixel-studio](https://github.com/gykim80/perfectpixel-studio) (MIT; Wails + Go + React desktop app) generates 8-direction character sprite sheets with 100+ motion presets from a text prompt and exports a sprite sheet, `manifest.json` and Aseprite-compatible JSON. Approach: treat it as an *external, optional asset-pipeline tool*, not a vendored dependency — add a framework-side importer (`EditorImportPlugin` or a `tools/` script) that turns its `manifest.json`/Aseprite JSON into `SpriteFrames` resources, with unit tests on a small checked-in fixture. License: MIT is compatible with this repo's license; keep its copyright notice if any code is copied. Open questions: generated art needs paid AI provider keys (Gemini/OpenRouter/fal.ai/BytePlus) and is non-deterministic, so it must stay outside `tools/gen_assets.py` and its byte-identical CI check (FR3); provider terms for generated images need review before shipping such art in a game.
